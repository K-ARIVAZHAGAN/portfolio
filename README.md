# Arivazhagan — portfolio template

A responsive, dependency-free portfolio. Open `dist/index.html` or serve `dist` with any static server. Includes project filtering, accessible project dialogs, a persistent theme toggle, and mobile layouts.

## Add your content

- `dist/index.html`: biography, headings, skills, contact links, and project cards.
- `dist/script.js`: project descriptions and focus areas.
- `dist/style.css`: colors, typography, layout, and responsive styling.

The three projects are explicitly illustrative concepts, not claims of completed client work. Replace them with your projects and images. The contact button currently links to your supplied GitHub profile. Add your email, LinkedIn, resume, and real project links when ready.

Typography uses Google Fonts with local system fallbacks. All project graphics are created in CSS; no image assets or build step is required.

## GitHub Pages

Publish the `dist` folder with your preferred static hosting provider. A GitHub Pages workflow is available in the local deliverable, but uploading it requires GitHub workflow permission.
